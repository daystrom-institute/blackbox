# Retired atom execution

Blackbox no longer installs, invokes, resumes or delegates atoms. Compose reusable protocols in the caller harness. Use its native code, refactor, shell and file capabilities for deterministic operations; use bro_exec and bro_resume for model turns. Stored atom artifact receipts remain readable with bbox_artifact_list(kind="atom"). They do not activate code.
