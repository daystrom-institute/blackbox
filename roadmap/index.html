    Roadmap — blackbox¶

    Proposed¶

    Feature: Workflow template library¶

    • Priority: high
    • Project: /home/invidious/repos/transcript-search

    Named sub-workflow templates stored in a JSON-backed registry, referenced by id instead of inlining full specs. Mirrors rule-packet composition via Apply{}. Lets keystone/triage/crucible patterns be one-line references. Thread: thread-7e2bd735.

    Feature: Workflow engine persistent resume¶

    • Priority: high
    • Project: /home/invidious/repos/transcript-search

    bro orchestrate resume — re-enter a paused/errored arc from its last completed node boundary. Requires persistent full-output snapshots, disk-backed running_arcs registry, and storing workflow JSON as handoff_doc on the arc thread. Survives daemon restarts. Thread: thread-7e2bd735.

    Infrastructure: Disk-backed WaitStore¶

    • Priority: high
    • Project: /home/invidious/repos/transcript-search
    • Thread: thread:thread-f92e54d5

    Suspended arcs (Wait nodes) currently use an in-memory wait store — daemon restart drops all pending waits. Persist to disk so webhook/poller/cron signals resume correctly after restart. Blocks reliable workflow resume.

    Debt: Opencode provider instruction loading¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    Opencode-based bros (glm/deepseek) don't follow @-imports in AGENTS.md and don't load BLACKBOX.md guidance. They fall back to grep/read instead of using the agentic surface. Needs either opencode-side @-import support or a pre-dispatch injection path. Thread: thread-6465976e.

    Refactor: File virtual entity refactor¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    Currently chunk[0] proxies as the file entity for IN_FILE edges. Introduce a first-class file entity that owns metadata (path, language, chunk count) and links to its chunks. Clean up the IN_FILE schema so inspect-by-file returns structured info instead of repurposing a chunk. Thread: thread-61749e32.

    Feature: Scout subagents with structured evidence return¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    Composable scout subagents that return query paths (entity refs + path IDs) instead of prose answers. An orchestrator dispatches a scout, the scout runs the 5-step agentic opening sequence, returns structured evidence bundles the orchestrator can inspect without re-walking the graph. Thread: thread-f4e4624f.

    Debt: Wire cancel_arc routing verdict¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    Cancel_arc routing verdict is documented but not wired through. The routing-packet consequent shape exists but the engine doesn't act on it. Needed for "PR closed without merge" events that should cancel the waiting arc.

    Feature: Language expert agent catalogue¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    Agents carry language-specific expertise via installed agent artifacts + tree-sitter-driven refactor plans. Currently have Java (lombokify, extract class/method, move field) and Rust (status + plan scaffolding). Need: Go, Python, TypeScript plan kinds + language-expert agent artifacts that know idioms and anti-patterns per language. Thread: thread-47dddbe8.

    Infrastructure: Auto-compact edge sidecars¶

    • Priority: low
    • Project: /home/invidious/repos/transcript-search

    Edge sidecar compaction exists (bbox_edge_compact) but isn't automated. Large projects accumulate append-only JSONL sidecars that slow EdgeIndex rebuilds. Add a daemon startup check: if sidecar > threshold (10MB?), auto-compact before loading. Or a periodic tick.

    Risk: Shell op sandbox / packet-gated allowlist¶

    • Priority: high
    • Project: /home/invidious/repos/transcript-search
    • Thread: thread:thread-fb32e54c

    Sandboxed Shell op currently runs with cwd from meta.worktree but no allowlist enforcement. Need packet-policy gating so workflow authors can't accidentally rm -rf or exfiltrate. Spec documented in workflows.md phase-next.

    Feature: MCP surfaces implementation¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    MCP surfaces are designed (design/mcp-surfaces.md) but not fully implemented. Surfaces let operators define per-context tool catalogs (e.g. "reviewer" surface only sees read tools + comment tools). Thread: thread-1bf496fc.

    Debt: Refactor / code-tools documentation page¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search
    • Thread: thread:thread-fa236a79

    Java refactor surface is landed (lombokify, extract class/method/field, move constant, add constructor/fields, boolean_getter_strategy, optional steps). Rust refactor has status + plan scaffolding. Need docs page covering bbox_refactor_plan/status/run, bbox_code_query/symbols/node_describe, and the plan catalog. Currently undocumented outside tool_docs.rs and sm-refactor system memories.

    Feature: Prompt file references for artifacts¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    Prompt-bearing artifacts (agents, brofiles) should support file:// references that get resolved at dispatch time, not inline blob storage. Lets prompts reference design docs, runbooks, or code files by path instead of copying content into the artifact JSON. Thread: thread-e8e9930b.

    Infrastructure: Multi-route embedding with multimodal support¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    Multi-route embedding config: replace hardcoded voyage/ollama provider slots with a named provider map. Add compatibility families so search never cross-queries unrelated vector spaces. Fix input_type (query vs document) for Voyage calls. Add multimodal provider for visual chunks (pdf_figure, slide_image, etc). Design: design/multimodal-embedding-routing.md. Phases 1-6.

    Feature: Commit-work provenance (WorkGraphLink)¶

    • Priority: high
    • Project: /home/invidious/repos/transcript-search
    • Thread: thread:thread-12980121

    Commit-to-work provenance — link commits to the threads, tasks, sessions, and notes that produced them. Requires a generic WorkGraphLink store (not overloading ThreadEdge), bbox_link MCP tool, automatic commit hook capture, and git notes import/export for cross-clone portability. Design: design/commit-work-provenance.md. Phases 0-5 in the design doc.

    Feature: Workflow foreach/matrix and dynamic indexed access¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    Close the workflow turing-completeness gap: dynamic indexed array access (read/write vars at computed positions), foreach/matrix primitives for iteration over collections, and conditional hook execution that doesn't require an LLM gate. Design: design/turing-completeness.md. Thread: thread-cba8bfa1.

    Feature: Refactor compound runs with rollback¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    Refactor compound runs — transactional multi-step refactor operations with rollback. bbox_refactor_run composes ordered primitive plans (extract, move, add module, wire router, format, cargo check) with hash checks and rollback across all touched files. Design: design/refactor-compound-runs.md. Landed for Rust/Java but needs broader language coverage.

    Feature: Code navigation and symbolic exploration tools¶

    • Priority: medium
    • Project: /home/invidious/repos/transcript-search

    Code navigation tools: bbox_code_query (tree-sitter queries against source files), bbox_code_node_describe (AST node at position), bbox_code_symbols (project-scoped symbol search with kind filtering), bbox_code_refs (per-file syntax reference extraction). Requires symbol_kind data model change (schema bump + reindex). Design: design/code-nav-symbolic-exploration.md. Phases 1-4.

    Debt: Embedding coverage gap for prose buckets¶

    • Priority: high
    • Project: /home/invidious/repos/transcript-search
    • Thread: thread:thread-117c04b5

    Knowledge/notes/threads buckets have source counts but zero indexed vectors in prod (observed 2026-05-07). The embedding queue may not be picking up these entity types, or the route may be misconfigured. Regression test needed: source_count > 0 implies indexed_count can grow under a healthy provider. Noted in design/multimodal-embedding-routing.md Phase 2.
